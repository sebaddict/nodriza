Plan de Acción · Módulo 02

Plan de Acción:
Desarrollo Web / App

Roadmap técnico completo para construir tu presencia digital. Desde wireframes hasta deploy en producción.

1

Arquitectura & Wireframes

Semana 1–2 · 10 días hábiles

Definición de estructura, flujos de usuario y wireframes de baja fidelidad.

    Mapa de sitioEstructura de páginas, jerarquía de contenido y flujos de navegación
    Wireframes de baja fidelidadSketches de cada página con bloques de contenido
    Definición de stack técnicoReact/Next.js, hosting, CMS, APIs necesarias
    Setup de repositorioGitHub con branching strategy, CI/CD y environments
    Prototipo interactivoFigma clickeable para validar flujos antes de desarrollar

Entregables de esta fase

  • Mapa de sitio
  • Wireframes Figma
  • Prototipo clickeable
  • Repo configurado
2

Diseño UI de Alta Fidelidad

Semana 3–4 · 10 días hábiles

Diseño pixel-perfect de cada página, componentes y estados interactivos.

    Design systemComponentes reutilizables, tokens de diseño, grid system
    Diseño de HomeHero, servicios, proceso, planes, CTA — desktop y mobile
    Diseño de páginas internasMódulos, planes, contacto, blog/recursos
    MicrointeraccionesHover states, transiciones, animaciones de scroll
    Review de accesibilidadContraste, tamaños, navegación por teclado

Entregables de esta fase

  • Design System Figma
  • UI completa desktop + mobile
  • Guía de interacciones
3

Desarrollo Frontend

Semana 5–7 · 15 días hábiles

Construcción técnica del sitio con React/Next.js y optimización de performance.

    Setup Next.js + TailwindConfiguración de proyecto, linting, TypeScript
    Desarrollo de componentesHeader, footer, cards, buttons, forms, modals
    Desarrollo de páginasImplementación de cada página según diseño UI
    Optimización de performanceLazy loading, image optimization, code splitting
    SEO técnicoMeta tags, sitemap, schema markup, Open Graph
    Testing cross-browserChrome, Safari, Firefox, Edge — desktop y mobile

Entregables de esta fase

  • Sitio funcional en staging
  • Reporte de Lighthouse 90+
  • Código en GitHub
4

Deploy & Go-Live

Semana 8 · 5 días hábiles

Configuración de producción, dominio, SSL y lanzamiento.

    Configuración de VercelDeploy automatizado, variables de entorno, preview branches
    Dominio + SSLConfiguración DNS, certificado SSL, redirects
    Analytics setupGoogle Analytics 4, Hotjar, eventos de conversión
    Testing final en producciónSmoke tests, formularios, links, mobile
    Documentación técnicaREADME, guía de deploy, variables de entorno

Entregables de esta fase

  • Sitio live en producción
  • SSL activo
  • Analytics configurado
  • Docs técnicos

¿Arrancamos?

Cada fase tiene checkpoint de validación. Vos aprobás, nosotros avanzamos.
